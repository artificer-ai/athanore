## Read this first: there is no remote

This checkout has **no git remote** (`git remote -v` is empty), and no
`.github/` directory. GitHub Actions therefore cannot run, and the task's
**Done** — "CI green on the branch" — cannot be observed. Write the
workflows correctly and verify everything that is verifiable locally,
then say plainly in the TaskReport that CI was not observed green
because there is nowhere to push. Do not claim a green CI run, do not
invent a run URL, and do not add a remote: whose remote it should be is
the operator's decision, not this task's.

## What this task is

Two workflow files that mirror the gate, so that the day a remote exists
they run the same checks `./scripts/test.sh` runs.

## What this task is not

- No changes to `athanore/` or to the gate scripts. If CI and
  `./scripts/test.sh` disagree about what green means, the gate is right
  and CI follows it.
- The `web` and `contract` jobs are **placeholders** until T007 and T008
  create `web/` and the OpenAPI snapshot. Write them, guarded so they do
  not fail on a tree that has neither yet.
- No release, publish, or tagging workflow. Packaging is 14's, later.

## Steps

1. `.github/workflows/ci.yml`:
   - job `python`: `uv sync --all-groups --all-extras`, then ruff,
     pyright, lint-imports, and `pytest --cov`, over a `python-version`
     matrix of `3.11`, `3.12`, `3.13` — the floor is tested, not just
     declared (D66). Run ruff, pyright and lint-imports **once**, on
     3.13, not once per matrix leg.
   - job `web`: `pnpm install --frozen-lockfile`, `pnpm typecheck`,
     `pnpm lint`, `pnpm test`, `pnpm build` (placeholder until T007).
   - job `contract`: T008's freshness check (placeholder until T008).
2. `.github/workflows/nightly.yml`: a Postgres service container and
   `uv run pytest -m postgres`. Register the `postgres` marker in
   `[tool.pytest.ini_options] markers` now — an unregistered marker is a
   warning today and an error under `-W error` later. The tests it
   selects arrive in T014; an empty selection must exit 0, not 5.
