# Design

**The design of Athanore is [`docs/v1/`](docs/v1/README.md), not this
file.** `DESIGN.md` was the MVP's single design document; it stayed with
the MVP, which is the neighbouring v0 checkout and is read here as a
behavioural specification rather than as code (D65 in
[`docs/v1/15-decisions.md`](docs/v1/15-decisions.md)). Everything that
holds for v1 is in the twenty numbered documents under `docs/v1/`, in
reading order from [`01-vision-and-scope.md`](docs/v1/01-vision-and-scope.md);
its one guardrail that outlived it — new capability attaches to an
existing seam before it gets a new concept — is kept as a convention
there, and every decision it carried forward is a row in
[`15-decisions.md`](docs/v1/15-decisions.md) marked `carried`.
